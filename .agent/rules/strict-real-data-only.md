# Strict Real Data Only Rule (실제 데이터 전용 수칙)

## Core Directive
- 디뷰(D-VIEW) 서비스 전반에서 **추정값, 시범(샘플) 데이터, Mock 데이터, 임의 가공 시세 데이터는 절대로 사용하거나 표시하지 않는다.**
- 국토교통부 등 공공기관의 100% 검증된 실제 공식 데이터만 수집 및 연동하여 제공한다.

## Office/Commercial Transactions Scoping
1. **사무실/지식산업센터 실거래가 (`recentTransactions`)**:
   - 국가 공식 신고 제도가 없는 상업용 임대차(전월세) 추정 데이터는 임의로 생성하거나 렌더링하지 않는다.
   - 국토교통부 공식 상업·업무용 매매 실거래가(`RTMSDataSvcNrgTrade`) 공공 API를 통해 수집된 100% 실제 매매 거래 데이터만 바인딩하여 표출한다.
   - 실제 매매 데이터가 없는 건물 또는 기간의 경우, 임의 데이터를 생성하지 않고 정직하게 `"등록된 실거래 내역이 없습니다."` 메시지만 노출한다.

2. **UI 노출 명확화**:
   - 상업용 부동산 실거래 탭은 100% 국토교통부 실제 매매 실거래 데이터 전용으로 작동하도록 조치한다.
