# 로컬 개발 서버 실행 워크플로우

사용자가 "로컬호스트 오픈" 또는 이와 유사한 프롬프트를 입력하면 다음 단계만 간결하게 실행합니다.

1. **개발 서버 상태 확인 및 실행**:
   - `manage_task` 도구를 통해 `npm run dev` 태스크가 이미 실행 중인지 확인합니다.
   - 실행 중이지 않다면 `frontend` 디렉토리에서 `npm run dev`를 백그라운드 태스크로 실행합니다.
   ```powershell
   cd frontend
   npm run dev
   ```
   - 불필요한 대형 마크다운 문서의 아티팩트 복제 생성은 수행하지 않습니다.
